# 眼部平扫节拍器

给眼部左右平扫训练用的节拍器。手机、平板、电脑都能用，打开网页即可，不用安装。
https://haru-f-hub.github.io/jiepai/

**默认设置：52 拍/分钟 · 每组 8 个来回 · 共 3 组 · 组间休息 10 秒**

## 怎么用

1. 点「开始」。先响 3 下预备拍（屏幕倒数 3、2、1）。
2. 预备拍结束，正式训练开始。**每响一下，眼睛移到亮起的那一侧。**
   - 第 1 响 → 看向**左**边
   - 第 2 响 → 看向**右**边（到这里算完成 1 个来回）
   - 第 3 响 → 看向**左**边 …… 如此往复
3. 一组做完会自动休息，屏幕倒数，时间到自动开始下一组。
4. 三组做完有结束提示音。中途可以随时「暂停」「重置」。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 节拍 | 52 | 每分钟响多少下。下面有 40 / 52 / 60 / 80 快捷键 |
| 每组的来回数 | 8 | 1 个来回 = 2 拍 |
| 做几组 | 3 | |
| 组间休息（秒） | 10 | 设为 0 就是连着做完 |
| 开始前的预备拍 | 3 | 设为 0 就是按下去立刻开始 |
| 圆点的显示方式 | 跳动 | 「跳动」= 圆点瞬间出现在端点；「平滑扫过」= 圆点匀速从一头移到另一头 |
| 音量 | 70% | 旁边有「试听」按钮 |

设置会自动记住，下次打开还是上次的样子。点「恢复默认」可以回到 52 拍 / 8 来回 / 3 组。

**左右用的是同一个音高**，所以光靠听分不出方向，必须看着屏幕：左半屏或右半屏会亮起来，圆点也会跳到对应的一侧。

## 关于准确性

节拍器最容易踩的坑，是用 `setInterval` 每隔一段时间响一声——它的误差会累积，几十拍之后就明显走偏。

这里用的是 Web Audio 的「提前排程」：先把未来 0.12 秒内该响的声音，按精确时间点写进音频硬件的时钟，再由一个 25 毫秒的定时器不断往前补。**什么时候响由音频硬件时钟决定，不由 JavaScript 决定**，所以做十分钟也不会偏。

屏幕上的圆点读的是同一个音频时钟，所以看到的和听到的是同一时刻。

实测：52 BPM 下连续 48 拍，每拍间隔误差为 0 毫秒。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `style.css` | 样式 |
| `metronome.js` | 节拍引擎（计时 + 发声），对外暴露 `window.EyeSweepMetronome` |
| `app.js` | 界面逻辑：读设置、画界面、接按钮 |

没有依赖、没有构建步骤。直接用浏览器打开 `index.html` 就能跑；也可以放到任意静态服务器上。

## 手机上使用

- **添加书签**：浏览器里存成书签，下次一点就开。
- **添加到主屏幕**（推荐）：在 Chrome 里打开页面 → 右上角菜单 → 「添加到主屏幕」。之后从桌面图标点开，全屏显示，跟 App 一样。
- 训练时建议把屏幕自动锁定关掉，或者别切到别的应用——切走会让计时变慢。
